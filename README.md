# GitHub Ödevi

## GitHub Nedir?
GitHub, kodların saklandığı ve paylaşıldığı bir platformdur.

## Temel Özellikler
- Repository: Proje klasörü
- Commit: Değişiklik kaydı
- Branch: Farklı geliştirme dalı
- Push: Kodu GitHub’a gönderme
- Pull: Kodu GitHub’dan çekme

## Amaç
GitHub’ın temel kullanımını öğrenmek.
